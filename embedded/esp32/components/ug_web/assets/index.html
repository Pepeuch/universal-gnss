Quitter BASE — F9P / UM980 / UM982

F9P : interrompt le Survey-In ou quitte la position fixe. UM980/UM982 : passe en MODE ROVER générique, sans restaurer un ancien scénario rover. Le mode change pour tout le récepteur ; les messages du profil RTCM sont désactivés sur le port choisi. F9P : les clés de coordonnées ne sont pas modifiées. Unicore : aucun reset explicite n’est envoyé ; la conservation d’une ancienne configuration BASE n’est pas qualifiée. Sans sauvegarde, un redémarrage peut restaurer le mode BASE précédent ; SAVECONFIG mémorise toute la configuration Unicore actuelle. Un ACK ne prouve ni un arrêt physique ni une initialisation RTK terminée. UM981 reste exclu.

Télémétrie du récepteur

F9P : cycle de navigation et messages PVT/SAT/STATUS/DOP/GGA. Unicore : périodes des messages UG, sans changement du mode BASE/ROVER. La réception réelle dépend du débit UART et du récepteur.

Les sélections avancées de constellations F9P et de groupes de signaux Unicore utilisent l'API typée, uniquement pour un modèle vérifié. Elles ne sont jamais déduites d'un nom de profil.
