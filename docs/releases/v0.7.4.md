# Universal GNSS v0.7.4 — stable release notes

Status: **selected by the maintainer; prepared, not published** (2026-11-08).
The future tag must identify the approved, CI-validated commit on `main`.
No stable image digest or publication date is asserted here.

## Scope

v0.7.4 succeeds v0.7.4-rc6. Production GNSS sources, interfaces, configuration,
launch files and image build recipe remain unchanged from rc6 source
`d02e23f17d34e58f75f4c7a7f72f8d34ea766bfa`. Integration adds documentation,
reproducible campaign figures and test infrastructure. A Release-only library
provenance test now checks replay and NTRIP consumers together: every required
library must load somewhere, and every observed copy must resolve to this build.
No runtime dependency is added or removed by that test correction.

The rc6 runtime includes the portable receiver/protocol/transport/NTRIP stack,
ROS 2 receiver/replay/correction nodes and observation identity/freshness
protections. This release preparation introduces no new runtime feature.

## Field evidence and limits

The [8 November rc6 report](../validation/2026-11-08-rc6-passive-mowing.md)
retains its original commit, container identity, data and four reproducible
figures. The 173 functional samples span 57 min 20 s; a separate continuous
capture contains 20,100 publications. No invalid-fix publication, sequence
regression or production process restart was observed within that capture.
A natural RTK degradation recovered to Fixed in about 8.999 s while valid 3D
positions and corrections continued. Operator lifting and physical LiDAR
connection issues are context, not a proven GNSS failure mechanism.

This evidence applies to the exact rc6 setup in the report. A stable-tag rebuild
can resolve different upstream base/apt inputs and produce different digests.
It does not inherit physical qualification solely from unchanged source.
Historical matrices keep their own versions and are not relabelled v0.7.4.

logs for that feedback are unavailable. This is an explicit operational
acceptance decision, not a newly measured rc6 endurance PASS. Do not rerun
